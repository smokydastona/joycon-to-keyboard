First-time setup

Bind Bandit Web Flasher

Flash the two boards once, in order: ESP32-S3 first, then ESP32. After that, use the desktop app for normal updates.

Use Chrome or Edge Flash order: S3 -> ESP32
Your browser does not support Web Serial. Use Google Chrome or Microsoft Edge on desktop.

Quick steps

  1. Put the board in download mode.
  2. Click the matching install button.
  3. Pick the board's serial port.
  4. Repeat for the second board.
Step 1

ESP32-S3

The USB keyboard bridge that plugs into the PC.

Double-tap RESET, then install.

Step 2

ESP32

The Bluetooth host that talks to the Joy-Con.

Hold BOOT, tap RESET, release BOOT, then install.

Need help entering boot mode or picking a port?

ESP32-S3

  • Plug in over USB-C.
  • Double-tap RESET quickly.
  • Pick the new COM port that appears.

ESP32

  • Hold BOOT.
  • Tap RESET once.
  • Release BOOT and use the usual CP210x or CH340 port.

If no port appears, try a data-capable USB cable, a different USB port, or see the wiring guide and the latest release.
