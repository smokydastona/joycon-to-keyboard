🎮 Bind Bandit Web Flasher

Flash your ESP32 boards directly from the browser — no drivers, no ESP-IDF install needed.

⚠️ Your browser does not support Web Serial. Please use Google Chrome or Microsoft Edge on desktop.

⚡ Before you click Install — put your board in download mode

ESP32 (Bluetooth Host) — boards with a BOOT button

NodeMCU-32S, ESP-WROOM-32, or any board with both BOOT and RESET buttons

1Plug the board into your PC via USB.
2Hold the BOOT button (keep holding).
3While still holding BOOT, tap RESET once, then release BOOT.
4Click Install ESP32 below and pick the serial port (usually "CP210x" or "CH340").

ESP32-S3 (USB Keyboard) — Arduino Nano ESP32 & native-USB boards

These boards have NO BOOT button — use the double-tap method instead

1Plug the board into your PC via the USB-C port.
2Double-tap the RESET button quickly (within ~300 ms).
3A new COM port will appear — this is the ROM bootloader.
4Click Install ESP32-S3 below and pick that new port.

💡 Tip: Note your existing COM ports before double-tapping RESET. The new port that appears is the one to select. On Windows it usually shows as "USB JTAG/serial debug unit" or "USB Serial Device".

After the flash finishes, press RESET once (or unplug/re-plug) to run the new firmware.

ESP32-S3 — USB Keyboard

⚠️ Double-tap RESET to enter download mode, then click below.

Step 2

ESP32 — Bluetooth Host

The board that connects wirelessly to your Joy-Con (or compatible controller) over Bluetooth Classic and sends UART frames to the ESP32-S3.

⚠️ Hold BOOT → tap RESET → release BOOT, then click below.

How it works

  1. Put the board in download mode using the instructions above (different for each board).
  2. Click the Install button for the board you're flashing.
  3. Select the serial port in the browser dialog (the port that appeared after entering download mode).
  4. ESP Web Tools will erase flash (clean NVS) and write the latest firmware.
  5. Repeat for the second board.
  6. After flashing both boards, wire them together per docs/wiring.md.
  7. Download Bind Bandit (the helper app) from the latest release to configure key mappings, profiles, and future OTA firmware updates.
ℹ️ Notes & Troubleshooting
  • Browser support: Web Serial requires Chrome 89+ or Edge 89+ on desktop. Safari, Firefox, and mobile browsers are not supported.
  • Erase all flash is enabled by default (recommended for first-time flashing). This clears NVS settings — you'll reconfigure via the helper app.
  • ESP32-S3 first: Flash the S3 board first since it's the front of the dongle (USB to PC).
  • ESP32 download mode (BOOT + RESET): Hold BOOT, tap RESET, release BOOT. The COM port stays the same (CP210x / CH340).
  • ESP32-S3 download mode (double-tap RESET): Quickly tap the RESET button twice. A new port appears — select that one. If you pick the wrong port, unplug and try again.
  • "Reset into boot mode" keeps appearing?
    • ESP32: Unplug, then hold BOOT → plug in USB → wait 2 seconds → release BOOT.
    • ESP32-S3 (Nano ESP32): Make sure you double-tap RESET quickly (<300 ms). If it doesn't work, try again — timing can be finicky.
    • Try a different USB cable — charge-only cables won't work.
    • Try a different USB port on your PC (prefer rear ports on desktops).
  • OTA updates: After initial flash, future firmware updates are handled automatically by the Bind Bandit helper app — no need to return here.
🔌 Which serial port should I pick?
  • Arduino Nano ESP32 / ESP32-S3 native USB: In download mode the chip presents a different USB device than when running firmware. On Windows you should see a new COM port appear after entering boot mode — pick that one (often labelled "USB Serial Device" or "USB JTAG/serial debug unit").
  • ESP32 boards with a USB-UART bridge (CP2102 / CH340): The COM port stays the same in boot mode and normal mode. Pick the one that matches your USB-UART chip (e.g. "Silicon Labs CP210x" or "CH340").
  • No port appears at all?
    • Make sure you're using a data USB cable (not charge-only).
    • On Windows, install the CP210x driver or CH340 driver if your board uses one.
    • For ESP32-S3 native USB in download mode, Windows 10/11 should auto-install the CDC driver. If not, try a different USB port.
  • Tip: Unplug the board, note which ports are listed, plug the board back in (in download mode), and pick the new port.
