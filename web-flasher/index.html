🎮 Bind Bandit Web Flasher

Flash your ESP32 boards directly from the browser — no drivers, no ESP-IDF install needed. Just plug in, pick a board, and click Install.

⚠️ Your browser does not support Web Serial. Please use Google Chrome or Microsoft Edge on desktop.
Step 1

ESP32-S3 — USB Keyboard

The board that plugs into your PC. Enumerates as a USB HID keyboard + CDC serial COM port for the helper app.

Step 2

ESP32 — Bluetooth Host

The board that connects wirelessly to your Joy-Con (or compatible controller) over Bluetooth Classic and sends UART frames to the ESP32-S3.

How it works

  1. Pick a board above and click its Install button.
  2. Select the serial port in the browser dialog (the ESP32 board you plugged in).
  3. ESP Web Tools will erase flash (clean NVS) and write the latest firmware.
  4. After flashing both boards, wire them together per docs/wiring.md.
  5. Download Bind Bandit (the helper app) from the latest release to configure key mappings, profiles, and OTA updates.
ℹ️ Notes & Troubleshooting
  • Browser support: Web Serial requires Chrome 89+ or Edge 89+ on desktop. Safari, Firefox, and mobile browsers are not supported.
  • Erase all flash is enabled by default (recommended for first-time flashing). This clears NVS settings — you'll reconfigure via the helper app.
  • ESP32-S3 first: Flash the S3 board first since it's the front of the dongle (USB to PC).
  • Download mode: If the board doesn't appear as a serial port, hold the BOOT button while pressing RESET, then try again.
  • OTA updates: After initial flash, future firmware updates can be done from within the Bind Bandit helper app (no web flasher needed).
  • Already have the helper app? You can also flash from the Diagnostics → Initial Flash section inside the app.
