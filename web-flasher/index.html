First-time setup

Bind Bandit Web Flasher

First, flash the ESP32 host. Next, connect the two installer wires. Then this page will install the ESP32-S3 through the host for you. After that, use the desktop app for normal updates.

Use Chrome or Edge Order: ESP32 first, ESP32-S3 second Extra wires needed: GPIO21 and GPIO22
Your browser does not support Web Serial. Use Google Chrome or Microsoft Edge on desktop.
Step 1

Flash the ESP32 host

This is the NodeMCU ESP32 board. Put it into download mode by holding BOOT, tapping RESET, then releasing BOOT. After that, click the install button below.

Do this first. This board will install the Nano in Step 3.

Step 2

Add the installer wires

Leave the normal bridge wiring connected, then add the two extra wires below. They let the ESP32 host start the Nano installer mode automatically.

  • GPIO17 -> Nano D2 / GPIO5
  • GPIO16 <- Nano D3 / GPIO6
  • GPIO21 -> Nano B1 / GPIO0
  • GPIO22 -> Nano RESET
  • GND <-> GND
  • Nano VUSB OUT -> ESP32 5V / VIN

During setup, only the ESP32 host should be plugged into the PC.

Step 3

Install the ESP32-S3 through the host

Click the button below and choose the ESP32 host COM port. The page will use the host board to put the Nano into install mode and flash it for you.

Ready for Step 3.
  1. Unplug and replug the ESP32 host after Step 1 finishes.
  2. Click the button above and choose the host COM port.
  3. Wait while the page installs the Nano automatically.
  4. When it finishes, move the USB cable to the Nano ESP32-S3 for normal use.
Need help with wiring, ports, or recovery?

Host COM port

  • After Step 1, unplug and replug the ESP32 host normally.
  • Choose the CP210x or CH340 port for the NodeMCU board.
  • If you are not sure, unplug the board, check which port disappears, then plug it back in.

Recovery option

  • If Step 3 fails, you can still flash the Nano directly.
  • Plug the Nano in with USB-C, double-tap RESET, then use the fallback button below.
  • After the first install, the helper app handles normal updates.
Fallback: flash the Nano ESP32-S3 directly

Use this only if the host-assisted install does not work. Double-tap the Nano RESET button, then choose the Nano port directly.

If no port appears, try a data-capable USB cable, try a different USB port, or see the wiring guide and the latest release.
