First-time setup

Bind Bandit Web Flasher

Flash the ESP32 host first, wire the Nano installer leads, then let the browser flash the ESP32-S3 through the host. After first install, use the desktop app for normal updates.

Use Chrome or Edge Flash order: ESP32 -> host-assisted S3 Extra wires: GPIO21 / GPIO22
Your browser does not support Web Serial. Use Google Chrome or Microsoft Edge on desktop.
Step 1

Flash the ESP32 host

Use the normal ESP Web Tools flow for the NodeMCU ESP32-WROOM-32. Enter download mode with BOOT -> RESET -> release BOOT, then install the host firmware.

Do this first. The host becomes the Nano installer.

Step 2

Add the installer wires

Keep the normal bridge wiring, then add two temporary or permanent installer leads so the host can force the Nano into ROM download mode.

  • GPIO17 -> Nano D2 / GPIO5
  • GPIO16 <- Nano D3 / GPIO6
  • GPIO21 -> Nano B1 / GPIO0
  • GPIO22 -> Nano RESET
  • GND <-> GND
  • Nano VUSB OUT -> ESP32 5V / VIN

Keep both boards disconnected from the PC except for the host USB cable during this step.

Step 3

Install the ESP32-S3 through the host

Connect to the host's USB serial port. The page will tell the host to pull Nano GPIO0 and RESET, then flash the merged S3 firmware over the existing UART bridge.

Waiting for the host install step.
  1. Plug the ESP32 host into USB after flashing it.
  2. Click the button above and pick the host COM port.
  3. Wait for the page to prepare the Nano, flash it, then release it back into run mode.
  4. Move the USB cable to the Nano ESP32-S3 for normal use.
Need help with wiring, COM ports, or fallback flashing?

Host COM port

  • After Step 1, unplug and replug the ESP32 host normally.
  • Pick the CP210x or CH340 serial port for the NodeMCU board.
  • The host prints lines beginning with BBI when it is ready.

Fallback

  • If host-assisted flashing fails, you can still flash the Nano directly.
  • Use USB-C, double-tap RESET, and install from the advanced fallback below.
  • The helper app still handles normal updates after first install.
Advanced fallback: flash the Nano ESP32-S3 directly

Use this only if you cannot get the host-assisted path working. Double-tap the Nano RESET button, then pick the Nano port directly.

If no port appears, try a data-capable USB cable, a different USB port, or see the wiring guide and the latest release.
