Initial provisioning

Flash the same hardware pipeline the desktop app expects.

This page uses the same visual language as Bind Bandit: blueprint surfaces, sand secondary text, and bright action accents. Use it once for first-time flashing, then stay in the helper app for profiles, diagnostics, and OTA firmware updates.

Board order ESP32-S3 then ESP32
Connection model USB bridge + Bluetooth host
Your browser does not support Web Serial. Use Google Chrome or Microsoft Edge on desktop.

Download mode

Before you click Install, put the board in bootloader mode.

ESP32 (Bluetooth Host)

NodeMCU-32S, ESP-WROOM-32, or any board with both BOOT and RESET buttons.

1Plug the board into your PC via USB.
2Hold BOOT and keep holding it.
3Tap RESET once, then release BOOT.
4Click Install ESP32 and pick the matching CP210x or CH340 port.

ESP32-S3 (USB Keyboard)

Arduino Nano ESP32 and other native USB boards use the double-reset method.

1Plug the board into your PC via USB-C.
2Double-tap RESET quickly, within about 300 ms.
3A new COM port appears. That is the ROM bootloader.
4Click Install ESP32-S3 and pick that new port.

Tip: note your existing COM ports before double-tapping RESET. The newly appearing port is the one you want.

After flashing finishes, press RESET once, or unplug and reconnect, to boot the new firmware.

Step 1

ESP32-S3 - USB Keyboard Bridge

The board that connects to the PC. It enumerates as a USB HID keyboard and exposes the serial link the helper app uses.

ESP32 - Bluetooth Host

The wireless controller host that talks Bluetooth Classic to the Joy-Con and forwards framed UART events to the ESP32-S3.

Bluetooth Classic Flash second BOOT + RESET

Hold BOOT, tap RESET, release BOOT, then start installation.

Workflow

What happens after you click Install

  1. Enter download mode using the board-specific instructions above.
  2. Click the matching install button for the board you are provisioning.
  3. Select the serial port that matches the bootloader state you just entered.
  4. ESP Web Tools erases flash and writes the latest shipped firmware image.
  5. Repeat for the second board, then wire both boards together per docs/wiring.md.
  6. Download Bind Bandit from the latest release for mapping, diagnostics, and future OTA firmware updates.
Notes and troubleshooting
  • Browser support: Web Serial requires Chrome 89+ or Edge 89+ on desktop. Safari, Firefox, and mobile browsers are not supported.
  • Erase all flash is enabled by default for a clean first-time install. That wipes NVS state, which you will reconfigure in the helper app.
  • ESP32-S3 first: Flash the S3 board first because it is the front-facing USB side of the bridge.
  • ESP32 boot mode: Hold BOOT, tap RESET, release BOOT. The COM port usually stays the same.
  • ESP32-S3 boot mode: Double-tap RESET. A new port appears; select that one.
  • If boot mode keeps failing: try a different USB cable, a different port, and repeat the reset timing exactly.
  • OTA updates: Once both boards are provisioned, future firmware updates happen in Bind Bandit. You should not need to come back here for normal upgrades.
Which serial port should I pick?
  • ESP32-S3 native USB: boot mode creates a different USB device than normal runtime. Pick the new port that appears after the double-reset sequence.
  • ESP32 with CP2102 or CH340: the COM port is usually the same in runtime and boot mode. Pick the port associated with that USB-UART bridge.
  • No port appears: verify the cable supports data, and install the correct CP210x or CH340 driver if your board uses a USB-UART bridge.
  • Practical check: unplug the board, note the current port list, then reconnect it in boot mode and choose the newly added or matching port.
