# Helper App UI Pack (Tkinter)

This folder provides requested UI artifacts for the **Bind Bandit** app (`helper-app/joycon_helper/app.py`).

Deliverables in this pack:

- UI mockup: see below
- UI backgrounds: `default/backgrounds/background.png` (light) / `dark/backgrounds/background-dark.png` (dark)
- UI theme tokens: generated by `tools/generate_ui_bundle.py` as `theme.json` (light + dark bundles)
- UI generator: `tools/generate_ui_bundle.py`
- UI architecture diagram: `architecture.md`
- Component guidance: `components.md`

The composited PNGs in `{theme}/backgrounds/` are **THE APP TRUTH**.

background — the app loads these directly instead of compositing at runtime.

## Mandatory artifacts (commit/push workflow)

**Pre-baked composites** (in `default/backgrounds/` and `dark/backgrounds/`):

Joy-Con composites (regenerated from root source art by `generate_ui_artifacts.py`):
- `joycons-none.png` / `joycons-left.png` / `joycons-right.png` / `joycons-both.png`

M913 composites (committed truth — NOT regenerated):
- `m913.png` / `m913-none.png` (Stock)
- `m913-incedius.png` / `m913-incedius-none.png` (IncediusMod)

`*-none.png` is the fully-grey disconnected state. `*-left.png` and `*-right.png`
composite the active side from the color source with the inactive side from the grey source.

Generate/update Joy-Con composites with:

```powershell
python tools/generate_ui_artifacts.py
```

This also regenerates **all button overlays** (1106 PNGs across 5 devices × 7 rainbow colours)
in `button_overlays/` via `tools/generate_button_overlays.py`.

**Keyboard images** (in `{theme}/misc/`):
- `keyboard.png` (light) / `keyboard-dark.png` (dark) — 1536×1024 RGBA overlays used by
  the keymap editor to show which physical keys are currently mapped.

**Button overlays** (in `button_overlays/`):
- Transparent 1536×1024 PNGs with a hand-drawn pencil-sketch highlight at each button position.
- Seven rainbow colour variants: red, orange, yellow, green, blue, indigo, violet.
- Default colour is **violet**.
- Generated by `tools/generate_button_overlays.py`.
- Layout: `button_overlays/{colour}/{device}/` (e.g. `button_overlays/violet/joycon/`).
- Devices:
  - `jc_*.png` — 16 buttons (Joy-Con)
  - `m913_*.png` — 16 buttons (Stock M913)
  - `inc_*.png` — 16 buttons (IncediusMod labels)
  - `kbd_*.png` — 103 keys (full keyboard)
  - `mouse_*.png` — 7 buttons (generic mouse)

### Enforcing generation on commit/push

Repo-local git hooks live in `.githooks/`. To enable them for your clone:

```powershell
pwsh tools/enable_git_hooks.ps1
```

Once enabled, commits/pushes will fail if Python isn’t available (this is intentional: the artifacts are mandatory).

## Theme

Tkinter does not have a full CSS pipeline, so the theme here is expressed as **tokens** you can apply consistently:

- `theme.json` contains:
  - semantic colors (bg, panel, text, accent, danger, etc.)
  - spacing + radii hints (used for consistent padding)
  - typography hints (font family/size)

This pack does **not** force the app to load the theme automatically (to avoid changing runtime behavior). It is designed so you can adopt it incrementally.

---

## Background

`background.png` / `background-dark.png` are full-window background images designed to:

- be non-distracting (so logs and JSON remain readable)
- fit a 980x720-ish canvas (current default window size)
- avoid any brand/trademark graphics

## UI generator

See `tools/generate_ui_bundle.py`.

It writes **two** UI bundle folders (light + dark) containing:

- `theme.json`
- `layout.json`
- `background.png` / `background-dark.png`
- `joycons.png` (compatibility overlay artwork for older backgrounds/tools)
- `backgrounds/` (pre-composited device-on-background PNGs)
  - `joycons-both.png` / `joycons-left.png` / `joycons-right.png` / `joycons-none.png`
  - `m913.png` / `m913-none.png`
  - `m913-incedius.png` / `m913-incedius-none.png`
- `pinouts.png`
- `README.md`

The dark bundle uses `*-dark.*` source files and the `sketchbook-ink-dark` theme tokens.

Example:

```powershell
python tools/generate_ui_bundle.py --out ./.ui-bundle
# Produces .ui-bundle/ (light) and .ui-bundle-dark/ (dark)
# Use --no-dark to skip the dark bundle.
```

### Dark mode selection

The helper app auto-detects the preferred theme:

1. `JOYCON_THEME=dark` environment variable (or `JOYCON_THEME=light`).
2. `--dark` command-line flag.
3. Windows 10+ dark mode via the `AppsUseLightTheme` registry key.
4. Falls back to light if none of the above match.
